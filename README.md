# AI Dev OS

An AI Operating System for Developers — talk to your codebase, investigate bugs, and automate workflows using multi-agent AI.

## What it does

- Chat with any GitHub repo using RAG (Retrieval Augmented Generation)
- Multi-agent system: Planner, Coder, Reviewer, Test agents
- MCP tool integrations: GitHub, Slack, Jira
- Persistent memory across sessions
- Automated workflows (PR reviews, incident investigation, daily summaries)

## Tech Stack

| Layer | Tech |
|---|---|
| Frontend | Next.js 14 (App Router) |
| Backend | Python + FastAPI |
| LLM | Anthropic Claude |
| Vector DB | Qdrant |
| Database | PostgreSQL |
| Tools | MCP (Model Context Protocol) |

## Phases

- **Phase 1** — Chat with repo, document upload, RAG search, GitHub integration
- **Phase 2** — Multiple agents, workflows, Slack integration
- **Phase 3** — Autonomous actions, memory, PR creation
- **Phase 4** — Voice, local agents, deployment analysis
